# Prévia comparativa de capítulos
Estado: demonstração isolada; não integra obras publicadas.

Página: `exemplos/livro-ilustrado/comparacao.html`. Exibe lado a lado o capítulo Markdown demonstrativo e uma revisão fictícia.

Destaques indicam blocos removidos/alterados (vermelho) e adicionados/alterados (verde). Imagens aparecem como referências textuais neste painel, para mostrar se foram mantidas, excluídas ou movidas. A ilustração completa é vista no leitor de prévia ilustrada `exemplos/livro-ilustrado/index.html`.

Os textos vêm de dois arquivos Markdown estáticos, sem carregar respostas de leitores ou executar Markdown como HTML. Nenhum botão aprova ou publica o texto. Em tela estreita, versões aparecem uma depois da outra.

**Limitação:** comparação por blocos, não por palavras; correspondência repetida pode não ser perfeita. Ainda falta conectar ao fluxo de revisão gerado, manter formatação literária e criar uma aprovação editorial explícita para obras reais.
