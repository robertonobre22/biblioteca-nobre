# Fase 3B — Transição de páginas

- Implementação experimental: animação suave ao avançar ou voltar no modo de páginas.
- Respeita a preferência do sistema por movimento reduzido.
- Modo contínuo permanece sem efeito visual de virada.
- O efeito ainda **não** reproduz fisicamente a virada de uma folha; não declarar flipbook tridimensional concluído.
- Pendente: validação visual em celulares/tablets/computadores, divisão de capítulos longos, figuras e integração do conteúdo real.
- Conteúdo: exclusivamente ficção de demonstração. Repositório privado, main intacta, sem publicação.
